# NISSE Design Language

## 11 --- Copywriting & Conversational Language

Version: 1.0

------------------------------------------------------------------------

# Objetivo

El lenguaje de NISSE debe transmitir que el usuario está colaborando con
un compañero de investigación.

Nunca debe sentirse como un software burocrático.

------------------------------------------------------------------------

# Personalidad

NISSE habla como un investigador.

Es:

-   curioso
-   claro
-   preciso
-   optimista
-   metodológico
-   inspirador

Nunca es:

-   arrogante
-   alarmista
-   robótico
-   excesivamente informal

------------------------------------------------------------------------

# Principios

1.  Hacer preguntas antes de asumir.
2.  Invitar a explorar.
3.  Explicar sin sobrecargar.
4.  Reconocer la incertidumbre.
5.  Mantener un tono sereno.

------------------------------------------------------------------------

# Voz del Companion

El Companion:

-   propone
-   observa
-   relaciona
-   resume
-   inspira

Nunca ordena.

Ejemplo:

✓ "Encontré tres relaciones que podrían enriquecer esta hipótesis."

✗ "Debe cambiar esta hipótesis."

------------------------------------------------------------------------

# Microcopy

## Botones

Preferir:

-   Explorar
-   Relacionar
-   Comparar
-   Generar
-   Profundizar
-   Documentar

Evitar:

-   Enviar
-   Procesar
-   Ejecutar
-   Confirmar

------------------------------------------------------------------------

# Estados Vacíos

Siempre invitan.

Ejemplos:

"Todo gran escenario comienza con una buena pregunta."

"No hay evidencia todavía. Agrega una fuente o conversa con un agente."

------------------------------------------------------------------------

# Loading

Narrativo.

Ejemplos:

-   Observando patrones...
-   Relacionando conceptos...
-   Contrastando evidencia...
-   Construyendo escenarios...
-   Explorando futuros plausibles...

------------------------------------------------------------------------

# Confirmaciones

Las confirmaciones deben reforzar progreso.

Ejemplos:

"La hipótesis fue incorporada al Workspace."

"Las relaciones fueron actualizadas."

------------------------------------------------------------------------

# Errores

Formato:

1.  Qué ocurrió.
2.  Qué significa.
3.  Cómo continuar.

Nunca culpar al usuario.

------------------------------------------------------------------------

# Incertidumbre

Usar expresiones como:

-   Parece indicar...
-   Es posible que...
-   La evidencia aún es limitada...
-   Existen interpretaciones alternativas...

Nunca presentar especulación como certeza.

------------------------------------------------------------------------

# Objetos Cognitivos

Los nombres deben ser descriptivos.

Ejemplo:

✓ "Escenario de movilidad autónoma colaborativa"

✗ "Escenario 4"

------------------------------------------------------------------------

# Títulos

Los títulos deben responder una pregunta.

Ejemplo:

"¿Qué señales están transformando el trabajo?"

------------------------------------------------------------------------

# IA

La IA nunca dice:

"He terminado."

Prefiere:

"He encontrado nuevas relaciones que podrían ser relevantes."

------------------------------------------------------------------------

# Terminología

Preferir:

-   Workspace
-   Investigación
-   Escenario
-   Evidencia
-   Hipótesis
-   Narrativa
-   Señal
-   Driver
-   Horizonte

Evitar:

-   Registro
-   Formulario
-   Ítem
-   Ticket
-   Caso

------------------------------------------------------------------------

# Reglas para Cursor

Al generar textos:

-   escribir para investigadores
-   evitar jerga administrativa
-   mantener frases breves
-   usar verbos de exploración
-   reconocer incertidumbre

------------------------------------------------------------------------

# Anti-patrones

Nunca:

-   usar lenguaje corporativo
-   abusar de signos de exclamación
-   escribir mensajes fríos
-   ocultar contexto
-   usar textos genéricos

------------------------------------------------------------------------

# Checklist

¿El texto invita a pensar?

¿Mantiene la calma?

¿Es metodológico?

¿Refuerza la exploración?

¿Suena como NISSE?

Si alguna respuesta es no, reescribir.
