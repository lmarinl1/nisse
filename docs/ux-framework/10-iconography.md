# NISSE Design Language

## 10 --- Iconography & Visual Metaphors

Version: 1.0

------------------------------------------------------------------------

# Objetivo

La iconografía de NISSE representa conceptos de investigación.

Los iconos no decoran.

Explican.

Orientan.

Reducen carga cognitiva.

------------------------------------------------------------------------

# Filosofía

Cada icono debe responder una pregunta.

¿Qué representa?

¿Qué acción comunica?

¿Qué concepto científico o prospectivo evoca?

Si un icono no responde esas preguntas, no debe existir.

------------------------------------------------------------------------

# Estilo

-   Outline predominante.
-   Geometría simple.
-   Esquinas ligeramente redondeadas.
-   Peso uniforme.
-   Sin efectos 3D.
-   Sin sombras propias.

Inspiración:

-   Lucide
-   Phosphor
-   Heroicons

# Metáforas Visuales

No utilizar metáforas empresariales.

Preferir:

-   telescopio
-   brújula
-   constelación
-   mapa
-   laboratorio
-   cuaderno
-   árbol
-   órbita
-   prisma

Evitar:

-   maletín
-   fábrica
-   engranajes como símbolo principal
-   hojas de cálculo

------------------------------------------------------------------------

# Tamaños

16 px → tablas y listas

20 px → navegación

24 px → acciones

32 px → protagonismo

Nunca mezclar tamaños arbitrariamente.

------------------------------------------------------------------------

# Color

Por defecto:

Color de texto.

Estados:

-   seleccionado
-   deshabilitado
-   activo
-   advertencia

No colorear iconos por decoración.

------------------------------------------------------------------------

# Composición

Todo icono debe respirar.

Separación mínima:

8 px del texto.

Nunca centrar la interfaz en iconografía.

------------------------------------------------------------------------

# Iconos + Objetos Cognitivos

Cada Objeto Cognitivo debe tener un icono consistente.

Ejemplo:

Hipótesis → diamante

Escenario → horizonte

Evidencia → documento

Narrativa → libro

Señal → radar

Driver → flecha

Incertidumbre → nube

Relación → enlace

------------------------------------------------------------------------

# Ilustraciones

Las ilustraciones deben ser técnicas.

Inspiración:

-   atlas científicos
-   mapas celestes
-   diagramas
-   esquemas

Nunca caricaturas.

------------------------------------------------------------------------

# Reglas para Cursor

Si existe un icono semánticamente correcto, reutilízalo.

Nunca inventes un icono para un concepto ya representado.

Prioriza claridad sobre originalidad.

------------------------------------------------------------------------

# Anti-patrones

Nunca:

-   mezclar estilos
-   usar emojis
-   abusar del color
-   usar iconos como decoración
-   duplicar significados

------------------------------------------------------------------------

# Checklist

¿El icono comunica un concepto?

¿Es consistente?

¿Puede entenderse sin texto?

¿Pertenece a la misma familia visual?

Si no, debe reemplazarse.
